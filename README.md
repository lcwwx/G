# 高校邦 本地刷课台

一个跑在自己电脑上的小工具：用本地浏览器登录高校邦（`*.gaoxiaobang.com`），**自动把课程视频播放完**，并把视频里弹出来的练习题答掉。

- 纯本地运行，只监听 `127.0.0.1:18800`
- 每次登录开一个**全新浏览器会话**，不共用 cookie，退出即销毁
- 密码只在内存里用到登录那一刻，**不写任何文件**
- 支持多个学校、多个账号，谁都能在页面上填自己的

---

## ⚠️ 先说清楚

这个工具做的是**替你把视频播放一遍**，它会触发平台自身的防挂机检测（比如切走窗口就暂停）。

使用前请你自己判断：

- 这类操作**大概率违反高校邦的用户协议**，被发现可能导致**课程成绩作废或账号封禁**；
- 作者不对任何后果负责，**请自行承担风险**；
- 不要拿它做代刷、收费、批量牟利——那是另一回事，也可能违法。

**它不替你做这些事**：专题讨论、结课作业、考试。那几个功能最多只生成草稿，提交按钮永远留给你自己按。

如果你只是想省掉"盯着 24 分钟视频"这件事，那它是干这个的。

## 安装 & 运行

```bash
npm install
node webapp.js
```

Windows 上也可以直接双击 `start.bat`。

启动后打开 **http://127.0.0.1:18800**。

第一次启动会自动生成 `access.json`，里面是一个 6 位访问口令，控制台也会打印出来。**本机访问也要输一次**——因为这个页面能操作真实浏览器，加个门比较安全。

## 怎么用

### 方式一：自己刷

1. 在「① 登录」填：学校网址（如 `xmut.gaoxiaobang.com`）、学号、密码
2. 点「登录」——**不用在浏览器窗口里点任何东西**，程序会自己填、自己点登录
3. 登录成功后出现课程列表，选一门点「刷视频」

### 方式二：排队（多人）

1. 在「排队刷课」里填学校、学号、密码、**课程关键词**（如 `形势与政策`，只刷标题含这几个字的课）
2. 点「加入队列」
3. 队列会一次一个人地跑：登录 → 挑课 → 刷视频 → 关浏览器 → 下一个

排队时密码只在内存里活到登录成功那一刻，之后立刻抹掉；服务一重启，队列就清空。

## 关于"写讨论 / 写作业"

页面上的「写讨论」「写作业」两个按钮会调用大模型生成正文：

- **讨论**：生成后填进回复框，**不点发布**
- **作业**：生成后存成 txt 并塞进上传控件，**不点提交**

这两步是故意的。提交是不可逆的（作业一旦被老师批阅就锁死），而且多个人用同一个模型写同一个题，交上去的段落会长得几乎一样——那是最容易被发现的破绽。所以最后那一下留给人。

要用这两个功能，需要配一个大模型 API。

### 配置模型

在 `webapp.js` 同目录建一个 `llm.json`：

```json
{
  "baseUrl": "https://api.deepseek.com",
  "model": "deepseek-chat",
  "apiKey": "sk-你的key"
}
```

或者用环境变量：

```bash
set GXB_LLM_KEY=sk-你的key
set GXB_LLM_BASE=https://api.deepseek.com
set GXB_LLM_MODEL=deepseek-chat
```

`baseUrl` 只要兼容 OpenAI 的 `/chat/completions` 协议就行（DeepSeek、百炼、Moonshot 等都可以）。

不配也能用，只是「写讨论」「写作业」会报错，刷视频不受影响。

## 已知限制

- **浏览器窗口必须保持在前台**。平台的防挂机逻辑是：窗口一失焦就 `pause()`。被遮住、最小化、切到别的窗口，视频都会停。这是平台的设计，不是 bug。
- **一次只能跑一个账号**。所有人共用同一个浏览器实例，同时跑会互相踢。
- **必须有图形界面**，不能在无头/服务器环境跑。
- 页面挂在公网时**务必改口令**，并且清楚：谁拿到口令，谁就能操作你电脑上的浏览器。

## 实现要点（给想改代码的人）

- **登录**：学校域名 → CAS 登录页（`tenantId` 由域名决定）。提交登录按钮时依次尝试 4 种方式：JS 触发 `.login_btn` → 回车 → Playwright 原生点击 → `form.submit()`。第一种最可靠，因为这个站的按钮常被透明遮罩挡住，Playwright 的"可点击性检查"会一直等。
- **登录失败**：错误信息在一个 `.autoTip` 弹窗里，而且那个弹窗宽高是 0，Playwright 判定"不可见"。所以直接轮询 DOM 读文本，不能等 `waitForSelector`。
- **课程页域名**：课程在 `<学校>.class.gaoxiaobang.com`，首页在 `<学校>.gaoxiaobang.com`，**不是同一个域名**，拼错会拿到空页面。
- **视频状态**：靠 `document.querySelector('video')` 的 `paused / currentTime / duration` 判断，不用猜。
- **切换视频时要加锁**：跳转那几秒页面还没有 video 元素，如果这时让定时器去判断"有没有视频"，会被误判成"这条没视频"然后秒跳下一条。这是本项目踩过的最深的坑。
- **视频内练习**：正确答案就在 `.gxb-video-quiz .correctAnswer` 的 `data` 属性里（页面标注"仅作练习，不计入课程成绩"）。
